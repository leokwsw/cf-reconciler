# 安裝指南（Node.js + PM2）

適用 Ubuntu/Debian。毋須 Docker。

## 1. 安裝 Nginx、Node.js 22與 PM2

```bash
sudo apt update
sudo apt install -y nginx ca-certificates curl unzip
sudo nginx -t
sudo systemctl enable --now nginx
node --version # 必須 >= 22；如未安裝，使用 NodeSource/nvm安裝受支援版本
corepack enable
corepack prepare pnpm@11.9.0 --activate
sudo npm install -g pm2
```

## 2. Cloudflare token

在 Cloudflare 建立 custom API Token：

- `Zone / Zone / Read`
- `Zone / DNS / Edit`
- Resources 只 include 要管理的 zones

不要使用舊 `cloudflare-watcher` source中的 token；若該 token 曾提交到 Git，立即 revoke/rotate。

## 3. 安裝應用

由 Git clone：

```bash
sudo git clone https://github.com/leokwsw/cf-reconciler.git /opt/cf-reconciler
cd /opt/cf-reconciler
sudo corepack pnpm install --frozen-lockfile --prod
```

亦可從 GitHub Actions成功 run 下載 `cf-reconciler-node` artifact，解壓至 `/opt/cf-reconciler` 後執行 `pnpm install --prod --frozen-lockfile`。Artifact包含 TypeScript `src/`、`package.json`、lockfile及 PM2 ecosystem；production直接以 `tsx`執行，不需要 build成 JavaScript。

## 4. 在專案 root 設定 secret 與 YAML

```bash
cd /opt/cf-reconciler
sudo cp .env.example .env
sudo chmod 0600 .env
sudoedit .env
sudo cp config.example.yml config.yml
sudo chmod 0640 config.yml
sudoedit config.yml
```

`.env` 只放：

```text
CLOUDFLARE_API_TOKEN=replace-with-scoped-token
```

`config.yml` 的 `nginx_generated_dir` 設為 `/etc/nginx/sites-enabled`。工具只會建立、更新或刪除 `cf-reconciler--*.conf`，不會碰其他網站設定。

TLS certificate及 private key必須使用完整絕對路徑，例如 `/root/ssl/leonardpark.dev/fullchain.cer` 及 `/root/ssl/leonardpark.dev/private.key`。Certificate建議 mode `644`、private key mode `600`；程式只引用它們，不負責續期。

## 5. 第一次驗證與同步

```bash
cd /opt/cf-reconciler
sudo node --import tsx src/cli.ts validate --config config.yml
sudo node --import tsx src/cli.ts sync --dry-run --config config.yml
sudo node --import tsx src/cli.ts sync --config config.yml
```

Dry-run只呼叫 Cloudflare read endpoints，不寫 DNS、檔案或 reload Nginx。

## 6. PM2 deployment與開機啟動

PM2需要 root權限才能寫 `/etc/nginx/sites-enabled`、讀 `/root/ssl` private keys及執行 Nginx reload：

`ecosystem.config.cjs`已將 PM2 `cwd`設定為專案 root，程式會使用 Node.js內建功能從該目前工作目錄載入 `.env`及 `config.yml`；secret不會寫在 PM2 config。

```bash
cd /opt/cf-reconciler
sudo pm2 start ecosystem.config.cjs
sudo pm2 status
sudo pm2 logs cf-reconciler
sudo pm2 save
sudo pm2 startup systemd -u root --hp /root
```

執行 `pm2 startup` 後，請複製並執行它輸出的 command，再次執行 `sudo pm2 save`。建議安裝 log rotation：

```bash
sudo pm2 install pm2-logrotate
sudo pm2 set pm2-logrotate:max_size 10M
sudo pm2 set pm2-logrotate:retain 7
```

更新部署：

```bash
cd /opt/cf-reconciler
sudo git pull --ff-only
sudo corepack pnpm install --prod --frozen-lockfile
sudo pm2 reload ecosystem.config.cjs --update-env
sudo pm2 save
```

## 7. 驗證與移除

```bash
sudo pm2 logs cf-reconciler --lines 100
sudo nginx -T | grep -F 'GENERATED BY cf-reconciler'
curl -I https://api.example.com/
```

移除不會刪除 Cloudflare records：

```bash
sudo pm2 delete cf-reconciler
sudo pm2 save
sudo find /etc/nginx/sites-enabled -maxdepth 1 -type f -name 'cf-reconciler--*.conf' -delete
sudo rm -r /opt/cf-reconciler
sudo nginx -t && sudo systemctl reload nginx
```

以上 `find`只刪除本工具帶前綴的設定檔；SSL certificate及 key不會被刪除。
